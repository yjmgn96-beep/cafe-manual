# 카페 관리 매뉴얼 검색기

PDF 매뉴얼을 검색 가능한 정적 웹 페이지로 변환한 도구입니다. 외부 서버·설치 없이 **`index.html`을 더블클릭**하면 바로 사용할 수 있습니다.

## 사용 방법

1. `index.html` 더블클릭 → 기본 브라우저(Edge / Chrome 등)에서 열립니다.
2. 상단 검색창에 키워드 입력 (예: `머신`, `세제`, `행주`, `라마르조꼬`, `딥클렌징`).
   - 제목·요약·본문 어디든 단어가 포함된 항목이 카드로 표시되며, 매치된 단어는 노란색으로 하이라이트됩니다.
   - 공백으로 여러 단어를 넣으면 모두 포함하는 항목만(AND 검색) 표시됩니다. 예: `머신 딥클렌징`.
3. 카드 클릭 → 상세 페이지로 이동. 본문 전체를 보거나 **"📄 PDF 원본 보기"** 버튼으로 PDF의 해당 페이지를 바로 열 수 있습니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 검색 UI (단일 파일, 외부 의존성 없음) |
| `data.js` | 섹션·요약·본문 데이터 |
| `[사업] 매장 관리 매뉴얼.pdf` | 원본 PDF (PDF 점프 기능에 필요) |
| `README.md` | 이 문서 |

위 4개 파일은 **같은 폴더에 함께** 있어야 합니다. 폴더째 다른 PC로 복사해서 사용할 수도 있습니다.

## 매뉴얼이 바뀌었을 때

1. 새 PDF로 `[사업] 매장 관리 매뉴얼.pdf` 를 교체합니다 (파일명은 그대로 유지하거나, 바꾼다면 `data.js`의 `pdf:` 값도 같이 수정).
2. Claude Code 세션에서 "**매뉴얼이 바뀌었으니 `data.js`를 다시 만들어줘**" 라고 요청하세요. 텍스트 추출 → 섹션 분할 → 요약 작성을 다시 수행해 `data.js`를 갱신해 드립니다.

## 현재 포함된 항목 (14개)

- **I. 제품별 사용 목록** (p.5~10)
  - 세제 별 사용 방법 / 행주 / 수세미 / 린넨
- **II. 청소주기와 방법** (p.11~26)
  - 장비 별 청소 주기
  - 라마르조꼬 / 라심발리 M39 / 라심발리 M23 머신 클렌징
  - 머신 딥클렌징 / 머신 워머 클렌징 / 머신 워머 딥클렌징
  - 디스트리뷰터 클렌징·딥클렌징 (홈아트 / 반킷)

> ⚠ 원본 PDF 목차의 **III. 장비 별 설정 방법**은 본문이 이미지로만 되어 있어 텍스트 추출이 되지 않아 현재 검색 대상에서 제외되어 있습니다. 필요 시 PDF 원본을 직접 확인해 주세요.

## 알려진 제약

- 브라우저에서 PDF를 새 탭으로 열 때 일부 브라우저는 `#page=N` 점프를 지원하지 않을 수 있습니다 (Edge·Chrome은 정상 동작).
- 표 형식의 본문은 고정폭 글꼴로 표시됩니다. 폭이 좁은 모바일에서는 가로 스크롤이 생길 수 있습니다.
